dust system maintenance log + procedure (v0.3, half migrated from the old wiki)

WEEKLY: knock the filter cleaner handle 10x each direction w/ system OFF. empty both bins when 2/3 full. NOTE bin 2 fills faster since the cyclone rebalance, check it midweek

blast gates - only open the gates ur using. every open gate = lost suction everywhere else. the jointer gate sticks, wiggle dont force

MONTHLY: check flex hose for splits esp. behind the bandsaw (rubs the wall). tape is a temp fix only, log it for replacement

filter minihelic gauge: green zone fine. yellow = clean filter this week. red = stop, clean now, do not run in red

?? someone keeps turning the system off while others are still cutting - the remotes are paired to ALL gates people. check the floor before killing power

static: the ducting is grounded, do NOT remove the ground wire when moving ducts. yes it matters. fine dust + static = the bad kind of exciting
